# Markdown 编辑器

欢迎使用 Markdown 编辑器！这是一个所见即所得的编辑工具，下面列出当前支持的常用语法。

## 标题

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

## 行内格式

**加粗**、*斜体*、~~删除线~~、==高亮==、`行内代码`，以及[链接](https://www.oneboxable.com)。

## 列表

- 无序列表项一
- 无序列表项二
- 无序列表项三

1. 有序列表项一
2. 有序列表项二
3. 有序列表项三

- [ ] 待办事项
- [x] 已完成事项
- [ ] 另一个待办

## 引用

> 引用可以跨多行。
> 也可以嵌套 **加粗** 和 `行内代码`。

## 代码

行内代码：`val name = "OneBox"`。

```kotlin
fun main() {
    println("Hello, Markdown!")
}
```

## 表格

| 能力 | 说明 | 状态 |
| :--- | :---: | ---: |
| 实时预览 | 编辑时即可看到效果 | 已支持 |
| 表格 | GFM 表格语法 | 已支持 |
| 任务列表 | 可勾选的待办 | 已支持 |

## 数学公式

行内公式：$E = mc^2$。

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

flowchart LR

## 使用方式

1. 右上角保存按钮：保存为 `.md` 文件
2. 右上角更多菜单：新建、打开、另存为、导出 PDF
3. 底部工具坞：编辑/源码切换、语音、撤销重做、格式、表格、复选框、插入内容
