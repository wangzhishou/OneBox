# Markdown 编辑器

欢迎使用 Markdown 编辑器！这是一个所见即所得的 Markdown 编辑工具。

## 功能特性

- **实时预览**：编辑时即可看到最终效果
- **丰富的格式支持**：标题、加粗、斜体、删除线、代码等
- **列表支持**：无序列表、有序列表、任务列表
- **插入功能**：链接、图片、引用、代码块、分割线

## 快速开始

### 文本格式

- **加粗文本**：选中文字后点击 **B** 按钮
- *斜体文本*：选中文字后点击 *I* 按钮
- ~~删除线~~：选中文字后点击删除线按钮
- `行内代码`：选中文字后点击代码按钮

### 标题

点击 H1、H2、H3 按钮可以插入不同级别的标题。

### 列表

- 无序列表项 1
- 无序列表项 2
- 无序列表项 3

1. 有序列表项 1
2. 有序列表项 2
3. 有序列表项 3

- [ ] 待办事项 1
- [x] 已完成事项
- [ ] 待办事项 2

### 引用

> 这是一段引用文字。
> 可以包含多行内容。

### 代码块

```kotlin
fun main() {
    println("Hello, Markdown!")
}
```

## 操作说明

1. 点击右上角 **打开** 按钮可以打开已有的 Markdown 文件
2. 点击右上角 **保存** 按钮可以将内容保存为 `.md` 文件
3. 点击右上角 **新建** 按钮可以创建新的空白文档
