# File Browser Module - Changelog

## [1.0.0] - 2024-12-24

### 初始发布 - 完整功能实现

#### 新增功能

##### 核心功能
- ✅ 文件浏览器组件，支持浏览文件和文件夹
- ✅ 双启动模式：
  - 传入 URI 自动定位并高亮目标文件
  - 不传参数从默认目录开始
- ✅ URI 支持：
  - `file://` scheme
  - `content://` scheme (Android Storage Access Framework)
- ✅ 文件导航：
  - 进入子目录
  - 返回上级目录
  - 导航堆栈管理
  - 返回按钮处理
- ✅ 文件操作：
  - 文件点击回调
  - 可配置的文件处理
  - 目录自动进入

##### 排序功能
- ✅ 按名称排序（字母顺序）
- ✅ 按修改时间排序
- ✅ 按文件大小排序
- ✅ 按文件类型排序（扩展名）
- ✅ 升序/降序切换
- ✅ 文件夹始终显示在前
- ✅ 排序状态持久化（导航时保持）

## 版本说明

版本号遵循语义化版本控制 (Semantic Versioning)：
- MAJOR.MINOR.PATCH
- MAJOR：不兼容的 API 更改
- MINOR：向后兼容的功能添加
- PATCH：向后兼容的问题修复
