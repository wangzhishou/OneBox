管理提词器文稿：支持列出全部文稿、读取文稿详情、创建新文稿、更新已有文稿、删除文稿。

适用场景：用户需要把演讲稿、台词、口播文案等保存到提词器，或查询、修改、删除已有文稿时使用本工具。

action 说明：
- list：列出全部文稿（返回 script_id、标题、字数、更新时间），无需其他参数。
- get：读取指定文稿的完整内容，必须提供 script_id。
- create：创建新文稿，必须提供 title，建议同时提供 content；返回新文稿的 script_id。
- update：更新已有文稿，必须提供 script_id；title 和 content 至少提供一个，未提供的字段保持原值。
- delete：删除指定文稿，必须提供 script_id；删除前建议先与用户确认。

注意：
- script_id 可从 list 结果中获取，不要臆造。
- 创建成功后，结果中的 deepLinks 可引导用户直接打开播放页开始提词。
- 本工具只管理文稿数据；播放中的字号、滚动速度、镜像等实时设置不在本工具范围内。
