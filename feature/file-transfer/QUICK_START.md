# 文件传输聊天功能 - 快速开始指南

## 🚀 快速开始

### 第一步：启动应用

1. 编译并运行应用到Android设备
2. 打开应用，找到"文件传输"功能
3. 确保手机和电脑在同一WiFi网络下

### 第二步：启动文件传输服务

1. 在"文件传输"页面点击 **"启动服务器"** 按钮
2. 应用会显示访问地址，例如：`http://192.168.1.100:8080`
3. 记下这个地址

### 第三步：在浏览器中访问

1. 在电脑浏览器中输入访问地址
2. 如果设置了密码，输入密码登录
3. 看到文件列表界面表示连接成功

### 第四步：开始聊天

#### 在手机端：
1. 点击右下角的 **蓝色聊天按钮**（带消息图标）
2. 在弹出的对话框中输入消息
3. 点击 **发送** 按钮

#### 在浏览器端：
1. 点击右下角的 **蓝色聊天按钮**
2. 聊天面板从右侧滑入
3. 在底部输入框输入消息
4. 点击 **发送** 按钮或按 **Enter** 键

## 💡 功能说明

### 未读消息提醒
- 当对方发送消息时，聊天按钮上会显示红色角标
- 打开聊天窗口后角标自动消失

### 消息显示
- **蓝色气泡**: 浏览器端发送的消息（在右侧）
- **灰色气泡**: 手机端发送的消息（在左侧）
- 每条消息都显示发送时间

### 自动刷新
- 浏览器端每2秒自动检查新消息
- 手机端实时接收浏览器的消息

## 🎯 使用场景

### 1. 快速传递文本信息
比如分享一段代码、一个链接、一段话

### 2. 远程协助
手机和电脑之间快速沟通

### 3. 临时笔记传递
在手机上看到的内容快速传到电脑

### 4. 文件传输确认
配合文件传输功能，确认文件是否正确

## ⚠️ 注意事项

1. **网络要求**: 手机和电脑必须在同一WiFi网络
2. **消息保存**: 消息仅在服务运行期间保存，停止服务后会清空
3. **浏览器兼容**: 支持Chrome、Firefox、Safari、Edge等现代浏览器
4. **防火墙**: 确保防火墙未阻止端口访问

## 🔧 故障排除

### 问题1: 浏览器无法访问
- 检查手机和电脑是否在同一WiFi
- 确认服务已启动（手机界面显示"服务运行中"）
- 尝试刷新浏览器页面

### 问题2: 消息发送后看不到
- 等待2-3秒（轮询延迟）
- 检查网络连接是否稳定
- 刷新浏览器页面重新连接

### 问题3: 聊天按钮不显示
- 确保服务已成功启动
- 检查是否有JavaScript错误（打开浏览器控制台）
- 清除浏览器缓存后重试

## 🎓 高级技巧

### 快捷键
- **Enter**: 发送消息
- **Shift + Enter**: 换行（浏览器端）
- **Esc**: 关闭聊天窗口（手机端）

### 批量操作
1. 可以连续发送多条消息
2. 每条消息独立显示
3. 自动滚动到最新消息

### 多设备支持
- 可以有多个浏览器同时连接
- 所有浏览器都能看到聊天记录
- 手机端是消息中心

## 📊 性能说明

- **延迟**: 约2秒（轮询间隔）
- **消息容量**: 理论上无限制（受内存限制）
- **并发连接**: 支持多个浏览器同时连接
- **网络占用**: 极低（每次轮询约1KB）
