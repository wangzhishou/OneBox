核心任务

使用Tailwind CSS创建一个响应式文件管理器界面，让用户通过浏览器在手机和PC间传输文件。
项目中已经有Tailwind css，引入地址是，这样方便共用
<script src="/static/js/tailwindcss.js"></script>

技术栈
HTML5 + Tailwind CSS
移动优先响应式设计
无JavaScript框架依赖
界面结构要求
移动端布局（<640px）
底部导航：文件、传输、设置
顶部：连接状态+存储空间
文件列表：两列网格布局
桌面端布局（≥768px）
左侧固定侧边栏
主内容区：文件操作区域
右侧：传输状态面板
必须包含的UI组件
✅ 文件列表（网格/列表视图切换）
✅ 路径面包屑导航
✅ 文件操作工具栏（上传/下载/删除）
✅ 传输进度条
✅ 拖拽上传区域
✅ 文件类型图标系统
✅ 多选操作界面
✅ 连接状态指示器
设计约束
颜色：蓝灰主色调（primary-600，gray-800/50/100）
间距：Tailwind标准间距（p-4, m-2, gap-4）
响应式断点：sm:640, md:768, lg:1024
交互反馈：hover:bg-gray-100, transition-colors
文件图标：使用Heroicons或简单emoji

核心交互

1. 点击文件：进入文件夹/预览文件
2. 长按/右键：打开操作菜单
3. 拖拽文件：到指定区域上传
4. 多选文件：批量下载/删除

文件展示信息

• 文件名（截断显示）

• 文件大小（自动格式化：KB/MB/GB）

• 修改时间（相对时间：今天/昨天/日期）

• 文件类型图标

必须实现的响应式特性

• 触摸友好：按钮高度≥44px

• 键盘导航：支持Tab键操作

• 暗色模式：prefers-color-scheme支持

• 加载状态：骨架屏占位

• 空状态：无文件时的友好提示

文件操作


上传：拖拽区域 + 按钮
下载：单选/多选后操作
删除：确认对话框
重命名：原位编辑
新建文件夹：模态框输入


传输状态展示

• 当前传输任务列表

• 进度条+百分比+速度

• 成功/失败状态提示

• 历史记录展示

浏览器兼容

• 核心功能支持：Chrome 80+, Firefox 75+, Safari 13+

• 降级方案：不支持拖拽时显示文件选择按钮

• 移动端：iOS Safari, Android Chrome

代码结构提示
'''html
<!-- 示例结构 -->
<div class="min-h-screen bg-gray-50">
  <!-- 响应式导航 -->
  <nav class="md:hidden fixed bottom-0 ...">移动导航</nav>
  <aside class="hidden md:block fixed left-0 ...">桌面侧边栏</aside>

  <!-- 主内容 -->
  <main class="md:ml-64 pb-16 md:pb-0">
    <!-- 路径导航 -->
    <!-- 工具栏 -->
    <!-- 文件列表 -->
    <!-- 传输状态 -->
  </main>
</div>
'''

验收标准
在手机/平板/桌面端测试正常

文件列表清晰可读

所有操作在3步内完成

加载状态有视觉反馈

错误情况有友好提示

支持键盘基本操作

触摸目标尺寸≥44×44px

按照这个提示词，可以生成一个功能完整、兼容性好的文件传输管理界面。
