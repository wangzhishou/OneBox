根据需求生成一个新的 AgentTool 草案，用于加速工具扩展。

返回结果包含：
1. 工具元数据：toolName、className、category、riskLevel、keywords、examples。
2. 参数 Schema：required 字段和 properties 草案。
3. 执行约定：入参解析、校验规则、成功/失败返回格式。
4. 文件与资源计划：Kotlin 文件路径、raw 描述文件名、strings/arrays key。
5. 代码模板：完整的 AgentTool Kotlin 骨架和 Hilt 绑定片段。
6. 接入说明：实现注意点、可联动的已有工具建议。

适用场景：
- 需要快速创建查询类、表单类、文件类、业务类工具时；
- 需要先让 AI 产出工具设计和代码骨架，再由开发者审核落地时；
- 需要保持与当前 AgentTool 架构一致的命名、资源、绑定方式时。

注意：
- 这是“草案生成器”，默认不会直接写入源码文件；
- 生成前应优先明确工具边界，避免做成过大而难维护的万能工具；
- 如果任务不确定具体能力，建议先调用 discover 做工具发现。
