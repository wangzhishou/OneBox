当你需要将文件输出到某个目录，或需要扫描/操作某个目录，但不知道具体路径时，调用 pick_folder 让用户通过系统目录选择器手动选取。

适用场景：
- 需要将生成的文件保存到用户指定的位置
- 需要批量处理某个目录下的文件
- 用户说"保存到这里"、"放在某个文件夹里"但没有提供路径

参数说明：
- message: 展示给用户的提示语，解释为什么需要选取目录（可选）

返回格式：
- 用户选取：{"status":"selected","folderUri":"file://..."}
- 用户取消：{"status":"cancelled"}

返回的 folderUri 是 file:// URI，可直接传给文件操作工具。

注意：
- 已知目录路径时直接使用，不要重复弹选择器打扰用户
- 只有在确实需要用户选择时才调用此工具
