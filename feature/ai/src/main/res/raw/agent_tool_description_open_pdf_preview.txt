在应用内的 PDF 预览屏中打开指定 PDF 文档。

功能说明：
- 支持远程 http(s):// 链接，会先下载到本地缓存目录再打开。
- 支持 content:// 和 file:// 本地 URI，直接打开。
- 打开后用户可以翻页、缩放、搜索、分享 PDF。
- 工具仅负责跳转屏幕，不返回页面操作结果（fire-and-forget）。

使用场景：
- 用户给出 PDF 下载链接，让你帮忙打开预览。
- 接收到上一步工具返回的 PDF URI，需要呈现给用户查看。
- 用户想浏览本地保存的 PDF。

参数：
- uri (string, 必填)：PDF 文档地址。

注意事项：
- 远程 PDF 会下载到应用私有缓存，已有同名缓存时会复用。
- 此工具默认对所有 URI 都尝试打开；如果 PDF 受密码保护，密码输入交给 UI 层处理。
- 如果只是要把 PDF 转成其他格式而不是预览，请改用 convert_pdf_to_images。
