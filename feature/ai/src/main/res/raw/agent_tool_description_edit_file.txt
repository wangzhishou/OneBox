对本地文本文件做局部编辑，适合代码 Agent 按计划执行小范围修改。输入支持本地路径、file:// URI，以及可解析为真实路径的 SAF content:// URI；工具会先统一转换为 file:// URI 后再修改文件。

支持动作：
- replace_text：按文本匹配替换，支持 replace_all
- replace_lines：按行号整段替换
- insert_before_line / insert_after_line：在指定行前后插入内容
- append / prepend：在文件尾部或头部追加内容

注意：
- 这是高风险写操作，需要用户确认
- 仅支持文本文件，无法解析成真实 file:// 的 URI 会直接报错
- 返回结果包含变更预览和目录 deeplink
