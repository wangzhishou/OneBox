执行文件写操作：删除、重命名、复制、移动、创建空文件、创建文件夹、写入文本内容。传入的本地路径、file:// URI、可解析的 SAF content:// URI 会先统一转换为 file:// URI，避免重启后 SAF 权限失效。

使用场景：
- 用户明确要求删除/移动/复制/重命名文件
- 创建新文件或文件夹
- 向文件写入或追加文本内容（write_file，支持 overwrite/append）

注意：目标路径必须明确时才调用，路径或意图不清时不要猜测。每个操作成功后返回 deeplink，可用于跳转到文件浏览器查看结果目录。此为高风险操作，会触发用户确认。对于无法解析成真实本地路径的 content:// URI，会直接报错。
