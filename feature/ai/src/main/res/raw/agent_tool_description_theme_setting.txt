用户要求某种风格（科技感、清新、商务、深色）时，不要 ask_user，也不要先 list。直接 action=set 写入一套协调配色。科技感或「深色 + 青色」用：
{"action":"set","night_mode":"Dark","primary":"#22D3EE","secondary":"#818CF8","mesh_gradient":"true","gradient_style":"Ocean"}
只有用户明确说「有哪几种」或「让我选」时才询问。

主题设置工具：读取 / 切换 / 微调当前主题。

三个 action，按用户意图选用：
- list：读取当前主题状态，响应包含：
  - `theme`：当前主题（颜色、日夜模式、玻璃 / 网格渐变 / glass_alpha / glass_border_alpha / gradient_style）
  - `gradientStyles`：所有合法的 `gradient_style` 取值（用其中之一）
  - `nightModes`：[Light, Dark, System]
  - `paletteStyles` / `colorSpecs`：全局色彩系统的全部合法取值
  - `colorSystem`：当前全局色彩系统（paletteStyle / contrast / colorSpec / expressiveMotion）
  - `builtinPresets`：[{"id","name"} 列表]，用于 action="apply" 切换预设主题
- set：修改当前主题的若干字段。**所有字段可选**，只传想改的即可；返回更新后的 theme。
- apply：切换到内置或用户主题。两种方式二选一：
  - `preset_id`（推荐，来自 list 响应的 builtinPresets），如 "builtin_sakura_pink"
  - 或 `preset_name`（大小写不敏感、模糊匹配），如 "SakuraPink"、"樱花粉"、"default"、"ocean"

action="set" 的字段（全部可选）：
- night_mode：Light / Dark / System
- primary / secondary / tertiary / surface：hex 颜色，格式 "#RRGGBB" 或 "#AARRGGBB"。
  "#" 前缀可省略，也接受 "0x" 前缀。示例：#3B82F6 或 FF6A8DFF。
- glass："true" 或 "false"（同时接受 1/0、yes/no、on/off）—— 玻璃透明效果
- liquid_glass："true" 或 "false" —— 液态玻璃
- mesh_gradient："true" 或 "false" —— 网格渐变背景
- gradient_style：`gradientStyles` 数组中的名字，如 "Lavender"、"Sunset"、"Ocean"
- glass_alpha：0.0 ~ 1.0 的浮点数 —— 玻璃透明度基准值，默认 1.0
  （0 会让玻璃层完全透明，仅在用户明确要求时使用）
- glass_border_alpha：0.0 ~ 1.0 的浮点数 —— 玻璃描边可见度，默认 0.17（17%）。
  0 表示完全隐藏描边，数值越大描边越明显；只影响描边，不影响玻璃本身的透明度
- palette_style：全局调色板风格，取自 list 的 `paletteStyles`，如 "Expressive"、"Vibrant"、"TonalSpot"（默认）
- color_spec：全局 Material 色彩规范，只能取 "Spec2021"（默认）或 "Spec2025"；
  Spec2025 即 Material 3 Expressive 规范（2025 Color Spec，配色更饱和鲜艳）
- expressive_motion："true" / "false" —— 是否启用 MaterialExpressiveTheme（表达性弹簧动效与形状）
- contrast：-1.0 ~ 1.0 的浮点数 —— 全局对比度，默认 0.0，负值降低对比度（如 -1.0 最柔和）
  （以上四项是**全局**色彩系统，不属于任何主题预设，切换预设不会改变它们）
- background_image：唯一取值 "clear" —— 清除自定义背景图，恢复纯色背景
- background_prompt：文字描述，AI 生成背景图并设为自定义背景（文生图，竖屏，
  可能耗时数十秒；代理路由消耗积分）。与 background_image 同传时以本参数为准

示例：
- "当前主题是什么" → {"action": "list"}
- "换成深色模式" → {"action": "set", "night_mode": "Dark"}
- "用樱花粉主题" → {"action": "apply", "preset_name": "樱花粉"}
- "主色改成蓝色" → {"action": "set", "primary": "#3B82F6"}
- "更清透一点" → {"action": "set", "glass_alpha": 0.75}
- "描边太明显了" → {"action": "set", "glass_border_alpha": 0.08}
- "不要描边" → {"action": "set", "glass_border_alpha": 0}
- "打开网格渐变，风格用薰衣草" → {"action": "set", "mesh_gradient": "true", "gradient_style": "Lavender"}
- "生成一张星空背景" → {"action": "set", "background_prompt": "深邃星空，银河，深蓝色调"}
- "换成 Material 3 Expressive 配色" → {"action": "set", "palette_style": "Expressive", "color_spec": "Spec2025", "expressive_motion": "true"}
- "用 2025 色彩规范" → {"action": "set", "color_spec": "Spec2025"}
- "对比度低一点" → {"action": "set", "contrast": -0.5}
- "清除背景图" → {"action": "set", "background_image": "clear"}

错误响应会带 `reasonCode`（如 "invalid_color"、"unknown_style"、"unknown_preset"）
和 `message`，部分错误还会带 `validOptions` 供下次自纠。
