# 万宝盒（WanBaoHe）功能模块清单

> 共 **123 个模块**：1 个 app + 23 个 core + 90 个 feature + 10 个 libs

---

## 一、图像查看与编辑

| 模块 | 中文标题 | 功能简介 |
|------|----------|----------|
| `image-viewer` | 图片查看器 | 全屏沉浸式图片查看器，支持多图滑动浏览、双击/捏合缩放（最大5倍）、网络图片下载 |
| `image-preview` | 图片预览 | 图片预览与管理，作为编辑流程入口，支持多图预览、跳转到编辑/裁剪/滤镜等子功能 |
| `single-edit` | 单图编辑 | 一站式单图编辑，集成裁剪、滤镜、绘制、色调曲线，支持尺寸调整、格式选择、质量控制、原图对比 |
| `draw` | 画笔绘制 | 自由绘制画布，支持钢笔/霓虹笔/荧光笔/模糊涂抹/像素化/文字/贴纸/斑点修复，多种形状路径和泛洪填充 |
| `markup-layers` | 图片创作 | 基于图层系统的完整图片创作工具：多图层（增删/排序/合并/混合模式/不透明度）+ 画笔/文字/形状/贴纸/裁剪旋转/基础调节，支持导出格式、质量与分辨率设置 |
| `crop` | 图片裁剪 | 图片裁剪，支持默认裁剪（带旋转）、无旋转裁剪、自由角点裁剪，多种形状轮廓和宽高比 |
| `image-stitch` | 图片拼接 | 图片拼接，支持水平/垂直/网格拼接，可配置对齐方式、间距、渐隐边缘 |
| `image-splitting` | 图片分割 | 图片分割，按行×列网格将单张图片拆分为多张子图 |
| `image-stacking` | 图片叠加 | 图片叠加，将多张图片按层叠方式合成到一张图上 |
| `image-cutting` | 图片裁切 | 图片精确裁切，通过设置水平/垂直起止百分比裁切指定区域，支持反选 |
| `compare` | 图片对比 | 图片对比，并排或叠加对比两张图片差异，支持滑块对比和像素级差异高亮 |
| `load-net-image` | 网络图片加载 | 网络图片加载器，输入URL自动解析页面图片资源，支持预览和下载 |
| `pick-color` | 图片取色 | 图片取色，点击/拖拽拾取像素颜色，支持平移和放大模式 |
| `collage-maker` | 拼图制作 | 拼图/拼贴画制作，最多10张图片拼贴，多种模板布局、间距、圆角、背景色配置 |

## 二、滤镜与特效

| 模块 | 中文标题 | 功能简介 |
|------|----------|----------|
| `filters` | 图片滤镜 | 图片滤镜工具，内置100+种滤镜（模糊、色彩调整、艺术效果、边缘检测、变形等），支持滤镜蒙版局部应用 |
| `gradient-maker` | 渐变生成 | 渐变图生成，支持纯渐变/渐变叠加/Mesh渐变，可配置渐变类型、颜色停止点 |
| `mesh-gradients` | Mesh渐变 | Mesh渐变收藏/浏览，在线下载渐变资源包，可跳转编辑器 |
| `noise-generation` | 噪声纹理 | 程序化噪声纹理生成，基于FastNoiseLite，支持OpenSimplex2/Perlin/Value等多种噪声类型 |
| `ascii-art` | ASCII艺术 | ASCII艺术转换，将图片转换为ASCII字符组成的文本艺术画 |
| `color-tools` | 颜色工具 | 颜色工具箱，颜色信息展示（HEX/RGB/HSL）、和谐关系分析、阴影/渐变生成、直方图分析 |
| `palette-tools` | 调色板提取 | 从图片中提取主色调生成调色板，支持Material You风格和自定义调色板导出 |

## 三、格式转换与压缩

| 模块 | 中文标题 | 功能简介 |
|------|----------|----------|
| `format-conversion` | 格式转换 | 图片格式转换（JPEG/PNG/WebP等），支持质量调节、EXIF保留、批量处理 |
| `resize-convert` | 尺寸调整转换 | 尺寸调整+格式转换一体化工具，支持宽高/预设/缩放模式，批量处理 |
| `weight-resize` | 按大小压缩 | 按目标文件大小压缩图片，实时显示压缩前后文件大小对比 |
| `limits-resize` | 限制尺寸缩放 | 限制尺寸缩放，在最大宽高限制内缩放，支持跳过/重编码/缩放三种模式 |
| `gif-tools` | GIF工具 | GIF动图工具，多图合成GIF动画，可配置帧率、重复次数、尺寸，支持逐帧预览 |
| `apng-tools` | APNG工具 | APNG动图工具，多图合成APNG动画，可配置帧延迟、重复次数 |
| `webp-tools` | WebP工具 | WebP动图工具，多图合成WebP动画，可配置帧延迟、重复次数 |
| `svg-maker` | SVG生成器 | SVG矢量图生成，将位图转换为SVG矢量格式 |
