Welcome to OneBox. We take the protection of your personal information seriously. The permissions below are **requested only while you are using the matching feature** — never in advance, and never on app launch:

**Photos, videos and file access**
Used to pick images/videos from your gallery for editing, to save generated or downloaded files, and to browse non-media files such as documents and archives.

**Camera**
Camera access is used for taking photos to upload and for document scanning, helping you capture content quickly and complete processing and saving.

**Access location metadata stored in media files**
Image location information can be edited while editing images, and is only used then.

**Record audio**
Microphone access is used to recognize your recordings when you use voice input.

**Location**
Used to show altitude, coordinates and compass bearing, and the city for weather.

**Contacts**
Used to pick a contact into a form. Contacts are never uploaded.

**Calendar**
Used to save to-dos as system calendar events.

**Notifications**
Used for file transfer progress and background playback controls.

**Install packages**
Used to install a new version after the update is downloaded.

**Sensors**
Shake-to-open customizable shortcuts, reducing interaction steps.

You can revoke or turn off any of these permissions at any time in system settings; declining only affects that one feature.
