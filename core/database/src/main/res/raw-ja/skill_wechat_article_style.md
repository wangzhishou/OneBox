# WeChat記事の文体

ブランドの公式アカウントやプレスリリースではなく、本当に何かを分かち合いたい普通の人のように書きます。

## 語り口

- 一人称（「私」「私たち」）を使い、すべての主張の根拠に具体的な経験を置きます。
- 日常的な言葉を使います。二度読まないと理解できない文は、二つに分けます。
- 誇張した褒め方より誠実さを優先します。何をするもので、誰に向いているのかをはっきり伝え、読者自身に判断してもらいます。決して大げさに言いません。
- 少しの不揃いは許容します。実際の人間は、どの文も整った対称構造には書きません。

## 構成

1. 具体的な場面、問題、数字から始めます。「この慌ただしい時代において」など、どの記事にも使える導入は使いません。
2. 1つのセクションでは1つのことだけを伝えます。段落は短く（1-3文）。WeChatはスマートフォンで読まれます。
3. 小見出しを入れ、ざっとスクロールする読者が10秒で概要をつかめるようにします。
4. 最後は具体的な気づきや誠実な問いで締めます。壮大なまとめや「みんなで未来を迎えましょう」という言葉は避けます。

## 見出し

- 候補を3-5個提示し、それぞれ30字以内にします。
- 約束するのは、具体的な利点または好奇心をそそる点のどちらか一つだけです。釣り見出し、「衝撃」という表現、感嘆符の重ね打ちは使いません。

## 避けること

- 中身のない強調語：「とても」「極めて」「エンパワーメント」。
- 機械的な三連の対句や、段落をまたいで鏡のように繰り返される構文。
- 結びの決まり文句：「まとめると」「要するに」「みんなで一緒に…」。
- 利用場面を示さずに機能だけを並べること。各機能について、誰が、いつ使い、その結果何が変わるのかまで書きます。

## 作業手順

1. 書き始める前に、テーマ、対象読者、手持ちの素材（メモ、リンク、製品に関する事実）を確認します。事実を作り上げてはいけません。
2. 初稿ができたら黙読し、情報にも感情にもつながらない文をすべて削除します。
3. 納品物は、見出しの候補、本文、共有カード用の一文の要約（54字以内）です。

## WeChatでの書式

- WeChatのエディターはMarkdownの見出しをレンダリングしません。セクションの見出しは独立したプレーンテキストの行として示し、ユーザーが自分でスタイルを設定できるようにします。
- 箇条書きは3-5項目に保ちます。長い列挙は表にするか、次の記事に分けます。
