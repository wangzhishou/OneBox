# 위챗 글쓰기 스타일

브랜드 공식 계정이나 보도자료처럼 쓰지 말고, 진심으로 무언가를 나누고 싶은 평범한 사람처럼 쓰세요.

## 문체

- 1인칭("나", "우리")으로 쓰고, 모든 주장 뒤에는 구체적인 경험을 두세요.
- 일상적인 단어를 쓰세요. 두 번 읽어야 이해되는 문장은 두 문장으로 나누세요.
- 과장된 칭찬보다 진솔함을 앞세우세요. 무엇을 하는 것인지, 누구에게 맞는지 분명히 말하고 독자가 스스로 판단하게 하세요. 절대 과장하지 마세요.
- 약간의 투박함은 괜찮습니다. 실제 사람은 모든 문장을 완벽하게 대칭되게 쓰지 않습니다.

## 구조

1. 구체적인 장면, 문제 또는 숫자로 시작하세요. "빠르게 변하는 이 시대에" 같은 어디에나 쓸 수 있는 도입부는 쓰지 마세요.
2. 한 섹션에서는 한 가지만 이야기하세요. 단락은 짧게(1-3문장) 유지하세요. 위챗은 휴대전화에서 읽습니다.
3. 소제목을 달아 빠르게 훑는 독자가 10초 안에 요지를 파악하게 하세요.
4. 마지막에는 구체적인 깨달음이나 진솔한 질문을 남기세요. 거창한 요약이나 "우리 함께 미래를 맞이합시다" 같은 말은 피하세요.

## 제목

- 후보를 3-5개 제시하고, 각각 30자를 넘지 않게 하세요.
- 구체적인 이점이나 호기심을 부르는 요소 하나만 약속하세요. 낚시성 제목, "충격" 같은 표현, 느낌표 나열은 하지 마세요.

## 피해야 할 것

- 내용 없는 강조어: "매우", "극도로", "임파워먼트".
- 기계적인 3단 병렬 구조와 단락마다 거울처럼 반복되는 문형.
- 마무리의 상투적인 표현: "결론적으로", "요약하면", "우리 모두 함께...".
- 사용 장면 없이 기능만 나열하는 것. 모든 기능에는 누가, 언제 사용하고, 사용 후 무엇이 달라지는지 담아야 합니다.

## 작업 순서

1. 쓰기 전에 주제, 대상 독자, 가진 자료(메모, 링크, 제품 관련 사실)를 확인하세요. 사실을 지어내지 마세요.
2. 초안을 완성한 뒤 마음속으로 읽으며, 정보도 감정도 더하지 않는 문장을 모두 지우세요.
3. 결과물은 제목 후보, 본문, 공유 카드용 한 문장 요약(54자 이내)으로 전달하세요.

## 위챗 서식

- 위챗 편집기는 Markdown 제목을 렌더링하지 않습니다. 섹션 제목은 일반 텍스트로 된 별도 줄로 표시해 사용자가 직접 스타일을 적용할 수 있게 하세요.
- 목록은 3-5개 항목으로 유지하세요. 더 긴 나열은 표로 만들거나 다음 글로 나누세요.
