OneBox — бесплатный набор инструментов «всё в одном» без рекламы: более 90 тщательно продуманных утилит в одном приложении — обработка изображений, работа с документами, ИИ-помощник и повседневные инструменты для продуктивности.

【Почему «OneBox»】
• One: все повседневные инструменты — в одном приложении
• Box: одна коробка, в которой помещается всё
Его цель — не просто «вместить побольше», а чтобы вам больше не приходилось переключаться между разными приложениями-инструментами.

【Инструменты для продуктивности】
• Телесуфлёр, заметки, список дел, колесо решений
• Вечный календарь, учёт расходов, облачный диск, трекер привычек

【Файлы и PDF】
• Инструменты PDF: объединение, разделение, извлечение изображений и текста
• Редактор Markdown с предпросмотром в реальном времени
• Шифрование файлов, извлечение обложек из аудио, редактирование EXIF изображений
• Файловый менеджер и передача файлов между устройствами

【Инструменты для изображений】
• Обрезка, поворот, изменение размера, конвертация форматов (HEIC / WebP / AVIF и другие)
• Фильтры, коллажи, склейка длинных изображений, инструменты для GIF
• Сканирование и генерация QR-кодов, инструменты цвета
• Сжатие изображений и конвертация форматов — всё обрабатывается локально, без загрузки на сервер

【Бытовые мелочи】
• Фото на документы, проверка скорости сети, камера с водяными знаками
• Стена пожеланий, песочные часы времени, установщик Apk.1
• Инструменты для экрана и медиа, мини-игры на досуге

【ИИ-помощник: не просто много функций】
Если бы дело было только в количестве функций, это умеют многие наборы инструментов. В OneBox встроен ИИ-помощник: не нужно искать нужный инструмент и запоминать шаги — просто скажите:
• «Преврати картинку в PDF.»
• «Запиши скриншот чека в расходы.»
• «Составь список дел.»
• «Проверь котировки акций.»
ИИ понимает, выполняет и отвечает — всё одним движением.
• Один вход для диалога с несколькими ведущими ИИ-моделями
• AI Agent может вызывать инструменты приложения, чтобы выполнять ваши задачи
• Помощники для написания, переписывания, пересказа и перевода текстов
• Собственные ИИ-движки и управление промптами

【Приложение, которое развивается само】
OneBox — не статичный продукт: у него есть «система самоэволюции на базе ИИ»:
пользователи оставляют отзывы и предложения → ИИ анализирует их как продакт-менеджер → код генерируется автоматически → тестирование и релиз.
Найденный вами баг, желаемая функция или идея по улучшению могут быть оценены и реализованы ИИ. Это значит, что чем дольше вы пользуетесь OneBox, тем лучше он подстраивается под ваши потребности.
