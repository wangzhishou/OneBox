Ang OneBox ay libreng all-in-one toolbox: 90+ tool para sa image, PDF, file at araw-araw na buhay — kasama ang tunay na AI assistant na hindi lang sumasagot ng tanong, gumagamit din ng toolbox para sa iyo.

【AI chat, gamit ang model na pinili mo】
• Isang entry point sa pangunahing mga model: OpenAI GPT, Claude, Gemini, Grok, DeepSeek, Qwen, OpenRouter
• Bukas sa third-party: ikabit ang kahit anong OpenAI-, Anthropic- o Responses-compatible API gamit ang sariling key — kahit lokal na model sa computer mo
• Voice input, image at file attachment, streaming na sagot, prompt library
• Tulong sa pagsulat, rewrite, summarize at translate
• AI content detector: tingnan kung ang text o image ay gawa ng AI

【Isang agent na talagang gumagawa ng trabaho】
• Kaya ng assistant ang 70+ tool sa app: image compression at format conversion, PDF merge at split, OCR at barcode reading, EXIF editing, watermark, bookkeeping, to-do, notes, cloud drive, web search at page reading
• Kaya rin nitong patakbuhin ang phone: tingnan ang screen, tap, swipe at type para tapusin ang gawain sa ibang app
• Built-in browser na kayang idrive: buksan ang page, basahin ang content, patakbuhin ang script
• Memory at skill ng agent: naaalala nito ang profile mo at ang gusto mong paraan ng trabaho

【Ilarawan mo — gagawin ito ng app】
Huwag nang maghanap sa menu. Sabihin ang gusto mo at gagawin ito ng OneBox na gumaganang tool o app:
• "Bigyan mo ako ng 8 pagpipilian sa kakainin ngayon." — pinupuno ng AI create sa decision wheel ang option mo
• "Travel planner." "Article style converter." — binubuo ng AI ang buong app, kasama ang screen at tool; i-refine sa chat: "gawing asul ang button, maglagay ng date picker"
• Dumarating ang sagot bilang totoong control — form, slider, date, time, color at file picker sa loob ng chat, hindi pader ng text
• Gumawa ng image mula sa text prompt, tapos i-edit, i-compress o i-convert sa parehong toolbox
• Bawat tool na may input ay may AI create entry: ilarawan mo at isusulat ito ng AI para sa iyo

【Ang toolbox, kapag mas gusto mong mag-tap】
• Mga image: crop, filter, collage, long-image stitching, GIF, Image Studio na may layer, brush, text, format conversion (HEIC / WebP / AVIF), compression — lokal lahat
• File at PDF: merge, split, extract ng text at image, Markdown editor na may live preview, file encryption, EXIF editing, device-to-device transfer
• Productivity: teleprompter, notepad, to-do, bookkeeping, habit tracker, calendar, decision wheel, record center na may AI insights (kalusugan, item, expiry, period)
• Pang-araw-araw: ID photo, QR scan/generate, speed test, watermark camera, unit converter, Text Card, I Ching divination, mini-games
• Ad Watch: manood ng rewarded ad para sa AI points — desisyon mo, hindi pinipilit

【DSH client: ang AI agent ng computer mo, mula sa phone mo】
Nagpapatakbo ka ng DeepSeek Harness (DSH)? I-scan ang QR code para mag-pair, tapos mag-approve, mag-follow up o mag-interrupt kahit saan, sa LAN o sa end-to-end encrypted na relay. Gumagana ito sa open-source na onebox-dsh-bridge plugin.

【Isang app na kusang nag-e-evolve】
Ang feedback mo → binabasa ng AI bilang product manager → nabubuo, nate-test at nare-release ang code. Bug report, feature request, maliliit na ideya — puwede itong mabuo nang ganito, kaya mas bagay sa iyo ang OneBox sa paggamit mo nito.
