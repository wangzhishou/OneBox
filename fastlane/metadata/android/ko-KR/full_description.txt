OneBox는 무료 올인원 도구상자입니다. 이미지, PDF, 파일, 일상생활을 위한 90개 이상의 도구에 더해, 질문에 답만 하는 것이 아니라 도구를 대신 조작해 주는 진짜 AI 어시스턴트까지 갖췄습니다.

【AI 채팅, 모델은 직접 고르세요】
• 주요 모델로 들어가는 창구 하나: OpenAI GPT, Claude, Gemini, Grok, DeepSeek, Qwen, OpenRouter
• 서드파티 API도 환영: OpenAI-, Anthropic-, Responses-호환 API라면 자신의 API Key로 연결할 수 있습니다 — 내 컴퓨터에서 돌아가는 로컬 모델까지
• 음성 입력, 이미지와 파일 첨부, 스트리밍 답변, 프롬프트 라이브러리
• 글쓰기, 다듬기, 요약, 번역 도우미
• AI 콘텐츠 감지: 텍스트나 이미지가 AI로 생성되었는지 확인

【실제로 일을 해 주는 Agent】
• 어시스턴트가 앱 안의 70개 이상 도구를 호출합니다: 이미지 압축과 포맷 변환, PDF 병합과 분할, OCR과 바코드 인식, EXIF 편집, 워터마크, 가계부, 할 일, 메모, 클라우드 드라이브, 웹 검색과 페이지 읽기
• 스마트폰도 직접 다룹니다: 화면을 보고, 탭하고, 스와이프하고, 입력해서 다른 앱의 작업을 끝내 줍니다
• AI가 조작하는 내장 브라우저: 페이지 열기, 내용 읽기, 스크립트 실행
• Agent 기억과 스킬: 당신의 프로필과 선호하는 방식을 기억합니다

【말하면 앱이 만들어집니다】
메뉴를 뒤질 필요가 없습니다. 원하는 것을 말하면 OneBox가 실제로 동작하는 도구나 앱으로 만들어 줍니다:
• "오늘 뭐 먹을지 후보 8개 골라 줘." — 결정 룰렛의 AI 생성이 선택지를 채워 줍니다
• "여행 플래너." "문체 변환기." — AI가 화면과 도구까지 포함한 앱 전체를 만듭니다. 채팅으로 다듬으세요: "버튼을 파란색으로 바꾸고 날짜 선택기를 추가해 줘"
• 답변은 진짜 컨트롤로 도착합니다 — 폼, 슬라이더, 날짜·시간·색상·파일 선택기가 채팅 안에 네이티브로 그려지며, 텍스트 더미가 아닙니다
• 텍스트 프롬프트로 이미지를 생성한 뒤 같은 도구상자로 편집·압축·변환
• 입력이 필요한 모든 도구에 AI 생성 진입점이 있습니다: 설명하면 AI가 대신 작성해 줍니다

【직접 탭하고 싶을 때 쓰는 도구상자】
• 이미지: 자르기, 필터, 콜라주, 긴 이미지 이어 붙이기, GIF, 레이어·브러시·텍스트를 갖춘 이미지 스튜디오, 포맷 변환(HEIC / WebP / AVIF), 이미지 압축, 비트맵을 SVG로 변환, 그라데이션 배경화면 만들기 — 모두 로컬 처리
• 파일 & PDF: 문서 스캐너, 병합, 분할, 텍스트와 이미지 추출, 실시간 미리보기 Markdown 편집기, 파일 암호화, EXIF 편집, 기기 간 파일 전송
• 생산성: 텔레프롬프터, 메모장, 할 일, 가계부, 습관 체크인, 캘린더, 결정 룰렛, AI 인사이트가 있는 기록 센터(건강, 물품과 유통기한, 생리)
• 일상: 비밀번호 금고, 증명사진, QR 코드 스캔과 생성, 인터넷 속도 측정, 워터마크 카메라, 단위 변환기, 대출 계산기, 나침반과 고도계, 자와 각도기, LED 전광판, 컬러 피커, 데드 픽셀 테스트, 주사위, 텍스트 카드, 주역 점, 미니 게임
• 광고 시청: 보상형 광고를 보고 AI 포인트 획득 — 볼지는 당신이 정하고, 강요는 없습니다
