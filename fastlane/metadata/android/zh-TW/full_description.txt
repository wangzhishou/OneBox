萬寶盒(OneBox)是一款免費的全能工具箱:90 多個涵蓋圖片、PDF、檔案與日常生活的小工具,再配上一個真正的 AI 助手——它不只是回答問題,而是直接替你操作這一整箱工具。

【AI 對話,用你想用的模型】
• 一個入口對話主流大模型:OpenAI GPT、Claude、Gemini、Grok、DeepSeek、Qwen、OpenRouter
• 對第三方友善:任何 OpenAI / Anthropic / Responses 相容介面,填上自己的 API Key 就能接,連電腦上跑的本地模型也行
• 語音輸入、圖片與檔案附件、串流回覆、提示詞管理
• 寫作、改寫、總結、翻譯助手
• AI 檢測助手:判斷一段文字或一張圖片是否由 AI 生成

【會幹活,不只是會聊天的 Agent】
• 助手能呼叫應用內 70 多個工具:圖片壓縮與格式轉換、PDF 合併拆分、OCR 與條碼辨識、EXIF 編輯、加浮水印、記帳、待辦、筆記、雲端硬碟、聯網搜尋與網頁閱讀
• 它還能操作手機:看螢幕、點按、滑動、輸入,替你在別的 App 裡把一整套流程走完
• 內建瀏覽器也交給它:開啟網頁、讀取內容、執行腳本
• Agent 記憶與技能:記得你的檔案,也記得你的習慣

【說一句,應用自己長出來】
不用再一層層翻選單。描述你要什麼,萬寶盒把它變成能用的工具或應用:
• 「幫我生成 8 個『今天吃什麼』的候選選項」——轉盤的「AI 建立」直接替你填好
• 「旅行計畫助手」「文章風格轉換器」——AI 把整個應用連介面帶工具一起搭出來;不滿意接著說:「把按鈕改成藍色,再加一個日期選擇」
• 回答不是一大段文字,而是真實控件:表單、滑桿、日期、時間、顏色、檔案選擇,直接在對話裡渲染出來
• 一句話生成圖片,再用同一套工具箱編輯、壓縮、轉格式
• 每個要輸入的工具都有「AI 建立」入口:你負責描述,AI 負責寫

【想自己動手時,工具都在這兒】
• 圖像:裁剪、濾鏡、拼圖、長圖拼接、GIF,圖層、筆刷、文字一體的「圖片創作」,格式轉換(HEIC / WebP / AVIF)、圖片壓縮、點陣圖轉 SVG、漸層桌布產生器,全部本地處理
